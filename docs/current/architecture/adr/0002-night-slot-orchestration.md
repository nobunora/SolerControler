# ADR 0002: 夜間の制御を23時・03時・07時へ分ける

## 決定

23時は待機モードへの切替だけを行い、03時にデータ取得・計画生成・必要時の強制充電・保存を集約し、07時に日中モードへ切り替える。

## 背景

夜間の判断は、実測SOCと最新予報を使うほど精度が上がる。一方、制御開始が遅すぎると目標SOCへ到達できない。23時の安全側モード、03時の最新条件での判断、07時の日中移行を分離することで、この両方を満たす。

## 結果

- 03スロットは最も多くの外部I/Oと失敗処理を担う。
- 23・07スロットへ予測や保存を追加しない。
- 時刻の正本は `scripts/deploy_gcp_jobs.ps1` とする。
