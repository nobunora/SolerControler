# ADR 0001: 複数バックエンドの保存を維持する

## 決定

SQLite、PostgreSQL、Firestore を保存先として維持し、共通のドメイン処理と表示用スナップショットを共有する。

## 背景

ローカル検証、代替本番、推奨本番で必要とする運用特性が異なる。保存先を一つに固定すると、ローカル再現性または本番運用の選択肢を失う。

## 結果

- バックエンド固有の接続・クエリ・トランザクションは `operations/` と `dashboard/` のアダプタに隔離する。
- 共通の集計・表示形状は共有する。
- 新しい保存処理は、各バックエンド間の契約テストまたは同等の検証を追加する。
